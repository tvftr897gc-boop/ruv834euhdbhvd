# Sculk Hosting documentation

This Mintlify repository contains customer-facing guides for the Sculk Hosting game panel. Pages are MDX files with YAML frontmatter. Navigation and branding live in `docs.json`.

Use active voice, second person, and concise steps. Use sentence case headings, bold exact panel labels, and code formatting for paths, commands, and file names. Use fictional addresses and no credentials in examples. Document customer controls visible on the relevant server type. Warn before actions that overwrite files, change software, or restore data. Use the live panel as the source of truth for exact UI wording.

Check navigation and internal links when adding or renaming pages. Preview with `npx mint dev` when available.
