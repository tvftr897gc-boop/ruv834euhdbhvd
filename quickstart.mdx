Follow these steps after purchasing a Sculk Hosting plan.

<Steps>
  <Step title="Open your activation email">
    Once payment is confirmed, Sculk automatically provisions your service. Use the link in your email to sign in to the billing portal and game panel.
  </Step>
  <Step title="Open the game panel">
    Visit [panel.sculkhosting.com](https://panel.sculkhosting.com) and select your server.
  </Step>
  <Step title="Finish the first-time installation">
    If prompted, select the game or server software you want to run. Minecraft servers can use software such as Paper, Purpur, Fabric, Forge, or another compatible server jar.
  </Step>
  <Step title="Start the server">
    Select **Start** on the Console page. Watch the console until the server reports that startup is complete.
  </Step>
  <Step title="Copy the server address">
    Copy the primary address shown in the panel and add it to your game's multiplayer server list.
  </Step>
</Steps>

<Warning>
  For Minecraft, you may need to accept the EULA before the first successful start. Open the generated `eula.txt` file, change `eula=false` to `eula=true`, save it, and restart the server.
</Warning>
