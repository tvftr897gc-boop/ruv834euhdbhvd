# Minecraft setup

Sculk supports common Minecraft server software, including Paper, Purpur, Fabric, Forge, and other compatible server jars.

## Choose your software

| Software | Best for |
| --- | --- |
| Paper or Purpur | Plugins, performance, and most public servers |
| Fabric | Lightweight modded servers and technical modpacks |
| Forge or NeoForge | Large mod ecosystems and many curated modpacks |
| Vanilla | The unmodified Minecraft server experience |

<Steps>
  <Step title="Select a version">
    Use the installer or version changer in the panel to choose your Minecraft version and server software.
  </Step>
  <Step title="Start once">
    Start the server so it can generate its initial files.
  </Step>
  <Step title="Connect">
    Add the panel's primary server address to Minecraft's multiplayer list.
  </Step>
</Steps>

<Tip>
  Only use plugins, mods, and server software built for the Minecraft version you selected.
</Tip>
