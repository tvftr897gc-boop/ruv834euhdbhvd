---
title: "Manage Minecraft players"
description: "Find players and understand the data shown in the panel."
icon: "users"
---

Open **MC Utils** → **Players** to search for someone who has joined the server. Select a player to inspect the information and available actions.

![The Players page with its search field and player details area](/images/panel/players.jpg)

The list is built from the server's files. Someone must join at least once before they appear. Player data may lag behind an online player's current state until the world saves. Actions run as console commands, so the server needs to be running.

If the list is empty, confirm that a player has joined this server and that you opened the correct server in the panel.
