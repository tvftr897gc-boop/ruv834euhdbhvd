# Sculk Hosting documentation

Customer guides for Sculk Hosting, built with Mintlify.

## Edit and preview

Pages are MDX files. Navigation, branding, and external links live in `docs.json`. Run `npx mint dev` at the repository root to preview changes locally.

Check the customer panel before documenting exact behavior. Write concise instructions in second person and bold UI labels. Never include real credentials or customer data in examples.

Review changes in a pull request before merging into `main`, which is connected to the documentation deployment.
